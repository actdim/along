# Milestone: v4.1.0 Code Intelligence Skills, Graph Workflows & Native MCP Ecosystem

## Intent

Milestone `v4.1.0` closes the usability and latency gap between low-level agent tools (MCP servers, Python engines) and developer/agent workflows.
It elevates `along-kb-search` to a deterministic native MCP tool while hardening its skill against LLM reasoning overhead, and introduces user-facing skills and lifecycle gates for the `code-review-graph` AST code intelligence engine.

## Target Scope & Core Issues

1. `[feat--kb-search-mcp-tool-and-skill-hardening]`:
   - Hardens `along-kb-search` skill instructions to prevent agents from reading or grepping files manually.
   - Exports `along_kb_search` as a high-speed native MCP tool for sub-100ms RPC retrieval across all supported agent runtimes.
   - Updates installers and `configure_mcp.py` to auto-register the Along MCP tool suite.

2. `[feat--code-review-graph-user-skills]`:
   - Introduces user-facing `/along-graph-impact` skill wrapping `get_impact_radius_tool` and `get_affected_flows_tool`.
   - Introduces user-facing `/along-graph-arch` skill wrapping `get_architecture_overview_tool`, `get_hub_nodes_tool`, and `get_bridge_nodes_tool`.
   - Embeds semantic blast radius gates into `along-team` and `along-wrap` workflows.

## Definition of Done for v4.1.0

1. `along-kb-search` executes deterministically in sub-100ms via either shell CLI or native MCP without agent file-reading loops.
2. Developers can execute `/along-graph-impact` and `/along-graph-arch` directly from the chat UI or CLI.
3. Pre-wrap and team refactoring stages enforce semantic blast radius inspection via `code-review-graph`.
4. All unit, contract, and hermetic tests pass with zero regressions.

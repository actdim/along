# Milestone: v4.3.0 Developer Experience, Packaging & Runtime Resilience

## Intent

Milestone `v4.3.0` hardens developer and agent ergonomics in Along development checkouts and execution environments:
1. **Automated Dev Environment**: Automates local virtual environment initialization and editable package installation (`along dev-env` or `.along/scripts/dev.py`) so developer IDEs and test runners work without manual path setup.
2. **Bootstrap Engine Resilience**: Supports inline `-c` execution in `scripts/alongkit/bootstrap.py` via `uv run` to eliminate crashes when scripts are invoked dynamically.
3. **Shell Probing Mitigation**: Enforces protocol rules and documentation against exploratory shell command execution for module symbol discovery.

## Target Scope & Core Issues

1. `[feat--dev-environment-setup-and-editable-install]`:
   - Initialize `.venv` and install `alongkit` in editable mode (`uv pip install -e .` or `.pth`).
   - Enable direct `pytest` and standard Python IDE tooling (linting, autocomplete) out of the box.

2. `[feat--bootstrap-resilience-and-subcommand-proxying]`:
   - Support `sys.argv[0] == "-c"` in `bootstrap.ensure_deps()`.
   - Proxy inline Python commands through `uv run` with declared dependencies.

3. `[docs--anti-pattern-shell-code-probing]`:
   - Formalize the `No Shell Code Probing` rule in `AGENTS.md` and skills instructions.
   - Direct agents to use `code-review-graph` MCP, static search, and Along CLI `--help`.

## Definition of Done for v4.3.0

- [ ] All three target issues implemented, tested with hermetic test suites, and marked done.
- [ ] Running tests via `pytest` works directly in the configured dev environment without `ModuleNotFoundError`.
- [ ] Inline `-c` invocations handled gracefully by `bootstrap.ensure_deps()`.
- [ ] Protocol documentation updated across `AGENTS.md` and skills references.

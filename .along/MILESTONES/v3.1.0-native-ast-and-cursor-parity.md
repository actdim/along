# v3.1.0: Native AST, Cursor Parity & Modular Decisions

## Intent

Expand Along agent support, internal code-intelligence capabilities, and documentation architecture following the v3.0.0 quality revision release:
1. **First-Class Cursor Support**: Full parity for Cursor Agent (`.cursor/rules/along.mdc`, MCP configuration, and single-agent fallback orchestration).
2. **Native AST Blast Radius Analyzer**: Built-in Python AST import/caller dependency graph extraction (`along blast-radius`), decoupling blast-radius auditing from fragile external third-party MCP servers.
3. **Modular Decisions & First-Class MkDocs Publication**: Transition from monolithic `.along/DECISIONS.md` to file-per-ADR storage (`.along/DECISIONS/ADR-*.md`), compile a lean projection board, and export ADRs into `docs/decisions/` with native MkDocs site navigation and search.

# Milestone: v5.3.0 Omnichannel Messaging Integration (Discord, Slack, Mattermost, Matrix)

## Intent

Milestone `v5.3.0` expands Along execution observability and human-in-the-loop control across enterprise messaging platforms:
1. **Omnichannel Messaging Gateways**: Abstract `NotificationGateway` supporting Discord (interactive embeds and run threads), Slack (Block Kit), Mattermost (on-premise corporate air-gap), and Matrix/Element (decentralized widgets).
2. **Unified Live Card Parity**: Replicate the single in-place status card and blocking permission approval workflow across all supported chat platforms.

# Milestone: v4.6.0 Clean-Turn Agent Loops & Resilient State Recovery

## Intent

Milestone `v4.6.0` applies the principles of clean-turn state isolation and rapid recovery to Along's multi-agent development engine (`along-team`):
1. **Clean-Turn Step Isolation**: Eliminates multi-turn chat bloat by synthesizing isolated prompt snapshots for each Living Plan step and Fix Loop retry, preventing error inertia and context poisoning.
2. **Zero-Turn State Recovery**: Implements automated environment drift detection before every step, ensuring the agent adapts immediately to external filesystem or Git changes without conversational delay.
3. **Dual-Tier Balance**: Combines strictly bounded operational token consumption for workers with full engineering provenance preserved on disk for auditing and review.

## Target Scope & Core Issues

1. `[feat--clean-turn-context-isolation-in-along-team]`:
   - Clean-turn prompt synthesis for Implementer workers.
   - Discarding intermediate failed reasoning traces in Fix Loops.
   - Decoupled asynchronous provenance logging in `execution_trace.md`.

2. `[feat--zero-step-state-recovery-and-drift-detection]`:
   - Pre-step drift detection probes via `git status` and file hashes.
   - Automated corrective alert injection into structured blackboard state.
   - Elimination of historical contradiction hallucinations.

- [ ] All target issues implemented, tested with hermetic test suites, and marked done.

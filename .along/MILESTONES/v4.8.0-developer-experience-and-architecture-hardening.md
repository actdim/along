# Milestone: v4.8.0 Developer Experience, Test Infrastructure & UI Core Integration

## Intent

Milestone `v4.8.0` delivers key developer experience, test runner flexibility, runtime error boundaries, and design system integration:
1. **Pytest Support & Filtering**: Native Pytest discovery, conftest integration, and -k test filtering in test.py.
2. **Domain Exceptions & Error Flow**: Elimination of bare sys.exit calls in commands, centralized alongkit domain exception hierarchy.
3. **UI Core Integration**: Full integration of @actdim/ui-core runtime, tokens, and component test suites in packages/dashboard-ui.
4. **Hermetic Test Suite Stabilization**: Protection against Windows stat-cache flips, content digest hashing, and parallel xdist execution support.
5. **CLI Safety Refinement**: False positive reduction for heredoc and package manager predicates.

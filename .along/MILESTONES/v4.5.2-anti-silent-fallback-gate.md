# Milestone: v4.5.2: Anti-Silent-Fallback Gate & Lifecycle Verification

## Intent

Eliminate silent fallback behavior where LLM agents quietly abandon gate-blocked sub-tasks, pivot to partial workarounds or alternative files, and close issues with false success reports. Introduce gate denial journaling, a reconciliation lifecycle, closeout verification in `along issue done` / `along wrap`, and a turn-termination gate on `Stop` events.

## Target Scope & Core Issues

1. `[feat--anti-silent-fallback-gate]`:
   - Session blackboard journaling of `PreToolUse` gate denials into `.along/.session/<slug>/gate_denials.jsonl`.
   - Mechanical closeout block in `along issue done` and `along wrap` when unresolved gate denials exist.
   - Declarative `unresolved_gate_denial` gate on `Stop` event in `default_gates.yaml`.
   - `--bypass-denial "<reason>"` flag for intentional, human-acknowledged omissions.

## Definition of Done for v4.5.2-anti-silent-fallback-gate

- [ ] `feat--anti-silent-fallback-gate` implemented, covered by hermetic tests, and marked done.
- [ ] Gate denials recorded to `.along/.session/<slug>/gate_denials.jsonl` upon any pre-tool hook denial.
- [ ] `along issue done` and `along wrap` refuse completion when unresolved denials remain.
- [ ] Declarative `Stop` gate blocks turn completion on unacknowledged denials.
- [ ] Clean ASCII and passing test suite (`python .along/scripts/test.py -q`).

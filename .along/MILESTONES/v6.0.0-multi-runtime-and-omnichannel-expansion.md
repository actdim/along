# Milestone: v6.0.0 Multi-Runtime Adapters & Omnichannel Chat Integration

## Intent

Milestone `v6.0.0` expands Along execution observability and human-in-the-loop control across diverse agent runtimes and enterprise messaging platforms:
1. **Multi-Runtime Adapters**: Dedicated integration adapters for Claude Code, OpenAI Codex, OpenCode (with native support for local models via Ollama/vLLM), and generic headless CLIs.
2. **Omnichannel Messaging Gateways**: Abstract `NotificationGateway` supporting Discord (interactive embeds and run threads), Slack (Block Kit), Mattermost (on-premise corporate air-gap), and Matrix/Element (decentralized widgets).

# Milestone: v5.0.0 Agent Run Protocol (AEP/ARP) & Observability Engine

## Intent

Milestone `v5.0.0` introduces the foundational execution control plane and observability architecture into Along:
1. **Agent Run Protocol (AEP/ARP)**: Universal execution event specification decoupling execution observation from model internal reasoning (Chain-of-Thought).
2. **OpenTelemetry Telemetry Pipeline**: Native OTLP event export combining OpenInference span hierarchies, OTel GenAI Semantic Conventions (`gen_ai.*`), OTel Process Conventions (`process.*`), and Along business attributes (`along.*`).
3. **Antigravity Runtime Integration**: Supervised process runner capturing lifecycle events via native hooks (`PreToolUse`, `PostToolUse`) and buffered output stream fallback.
4. **Interactive Execution Gate & Telegram Live Card**: Synchronous blocking hook for high-risk operations paired with a single in-place editable message (`editMessageText`) displaying progress and inline approval buttons.
5. **Repo-Local Containment**: Execution history, traces, and artifacts strictly anchored to the target repository `.along/` boundary.
6. **Operational Primitives & Playbooks**: First-class support for external systems (`ASSETS/`), executable runbooks (`PLAYBOOKS/`), and operational issue types (`incident`, `change`, `audit`).
7. **System Invariant Probes**: Generalized verification gates decoupling stage completion from code-only test runners to support live systems.
8. **Dual-Mode Documentation**: Transitioning Along documentation from code-only focus to dual-mode software engineering and autonomous operational control.

# Milestone: v4.0.0 Runtime Enforcement Gates & Worktree Workspace Isolation

## Intent

Milestone `v4.0.0` introduces active runtime barriers and execution sandboxing to Along.
While earlier versions established in-repo memory conventions and audited tool reliability,
`v4.0.0` replaces passive prose instructions with deterministic mechanical enforcement:
hard gates on tool calls via agent runtime hooks, and isolated git worktrees for agent tasks.

## Target Scope & Core Issues

The milestone groups two primary pillars:

1. `[feat--runtime-enforcement-of-prose-rules]`:
   - **Cross-Runtime Hook System**: Intercepts `PreToolUse`, `PostToolUse`, and `Stop` events across
     Google Antigravity, Claude Code, and OpenAI Codex.
   - **Hard Tool-Call Gates**:
     - `IssueAnchorGate`: Blocks source code edits without an active in-progress issue.
     - `TypographyGate`: Blocks writes containing forbidden non-ASCII typography or invisible characters.
     - `CliSafetyGate`: Blocks heredocs (`<<EOF`) and file content traveling through CLI arguments.
     - `CommitGuardGate`: Enforces active issue key binding in `git commit` commands.
     - `TestStopGate`: Forbids turn completion if code modifications were made without running tests.
     - `WrapStopGate`: Forbids turn completion if mandatory session wrap was omitted.
   - **Dual-Mode Governance**: Configurable `shadow` (telemetry/warning) vs `enforce` (hard block) modes.

2. `[feat--runtime-worktree-isolation]`:
   - **Runtime-Native Git Worktree Isolation**: Executes agent modifications in parallel directories
     without mutating the developer's primary working tree or disrupting IDE file watchers.
   - **Environment Readiness Contract**: Automatic junction/symlink sharing of dependencies (`node_modules`,
     `.venv`) and propagation of untracked configurations (`.env`).
   - **Fail-Fast Safety**: Immediate halt when worktree isolation with environment readiness is unsupported.
   - **Session State Preservation**: Junctioning or syncing `.along/` state to preserve session logs on teardown.
   - **Windows Locking Resilience**: Graceful handling of NTFS file locks during worktree cleanup.

## Associated & Synergistic Issues

- `[feat--programmatic-integrity-gates-and-git-guard]`: Automated Git index/lock self-healing and AST code patching.

## Definition of Done for v4.0.0

1. **Mechanical Enforcement**: PreToolUse and Stop gates actively intercept and block rule violations
   across at least Antigravity and Claude Code runtimes in enforce mode.
2. **Hermetic Testing**: Automated contract tests (`test_hooks.py`) and runtime harness tests verify
   blocking behavior, error codes, and audit logging.
3. **Pristine Worktree Workflows**: Tasks invoked with `--worktree` run entirely inside an isolated
   directory with working dependencies, merge back cleanly on pass, and leave zero leaked locks.

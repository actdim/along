# v3.0.0: Global Quality Revision

## Intent

`v3.0.0` is the version that ships with the audit fixes applied. It is deliberately a major
version rather than a patch line, because it is not a bug-fix batch: it is a global
re-examination of the product from the outside, asking one question of every advertised
capability - **does it actually work, and is there a test that proves it?**

The 2026-09-01 audit established that the answer is frequently no, and that the existing
test suite cannot tell the difference, because it asserts textual properties of the
documentation (version strings match, no em-dashes, front-matter present) rather than
behavior of the engines. Two examples found in the first hour: ADR retrieval returned zero
results in every released version, and the entity lifecycle CLI wrote an invalid status
while reporting success.

## Definition of Done for v3.0.0

Every feature claimed in `README.md`, `AGENTS.md`, and the eighteen `SKILL.md` files must
satisfy all four:

1. **Executable** - the documented command runs in a consumer repository, not only inside
   the Along source repository.
2. **Behaviorally tested** - a test exercises the actual outcome, not the presence of
   documentation about it.
3. **Honest** - the wording matches what the code does. Gates that cannot be enforced are
   not called mandatory; numeric claims are measured or removed.
4. **Non-destructive** - no engine can silently lose user content. Destructive paths have
   dry-run, backup, or explicit refusal.

## Feature Verification Matrix

Each advertised capability needs an owning issue and a behavioral test before v3.0.0 ships:

| Advertised capability | Audit verdict |
| :--- | :--- |
| Persistent in-repo memory (issues, ADRs, sessions) | Lifecycle CLI corrupted status; ADR retrieval blind |
| Provider-agnostic single protocol | `along-team` executable on one of four providers |
| LLM-Wiki KB with 95-98 percent token reduction | Unmeasured; naive substring ranking; no index |
| Nearest context boundary isolation | Design sound; not covered by tests |
| Zero bookkeeping overhead (18 skills) | Documented commands fail outside this repo |
| Idempotent KB synchronization | Second run overwrites hand-edited articles |
| Global link integrity gate | Skips `.along/`, the densest link source |
| Mandatory blast-radius gate | Depends on an unpinned MCP server that fails to start |
| Clean ASCII typography enforcement | Sanitizer destroys non-UTF8 files; skips `.along/` |
| Universal markdown rendering | 116 `file://` links, dead on every renderer |
| Release orchestration | Tests run after mutations; no rollback; no tag |
| Windows-safe / PowerShell resilient | Test suite crashes on non-UTF8 locale |

## Versioning Note

The project version stays at `2.2.8` while this plan is recorded. It moves to `3.0.0` only
when the Definition of Done above is met, so the major-version bump means something
verifiable rather than announcing intent.

## Non-Goals

- New features. This milestone is remediation, verification, and honesty.
- Rewriting the conceptual model, which the audit found sound.

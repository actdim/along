# Milestone: v4.5.0 Multi-User Git Concurrency & Automated Merge Resolution

## Intent

Milestone `v4.5.0` transforms Along into a robust multi-developer and multi-agent collaborative environment.
In multi-user repositories, parallel feature branches and agent sessions frequently experience Git conflicts across derived projections (`ISSUES.md`, `INDEX.md`), atomic entity metadata (`.along/ISSUES/`), LLM-Wiki documentation (`docs/topic--*.md`), and source code files.

`v4.5.0` establishes a tiered, test-gated merge automation subsystem:
1. Deterministic Custom Git Merge Drivers (`along git setup`) that guarantee non-conflicting `git pull`/`git merge` operations for projections and front-matter metadata.
2. Semantic conflict resolution engine (`along resolve`) for Knowledge Base documentation with automated markdown link verification.
3. Test-gated source code conflict resolution pipeline with automatic transactional rollback upon test failure.

## Target Scope & Core Issues

1. `[feat--git-merge-drivers-and-setup]`:
   - Custom Git merge drivers: `along-projection-driver` and `along-frontmatter-driver`.
   - `along git setup` command to configure `.git/config` and `.gitattributes`.
   - Automated registration during `along-init`.

2. `[feat--docs-semantic-conflict-resolution]`:
   - Discovery of unmerged markdown paths in `along resolve`.
   - Semantic 3-way conflict hunks reconciliation for markdown sections and headers.
   - Link integrity validation against `alongkit.markdown` and recompilation via `along-kb-sync`.

3. `[feat--test-gated-code-merge-pipeline]`:
   - Code conflict resolution engine for source files (`.py`, `.ts`, etc.).
   - Mandatory verification pipeline: syntax check, typography gate (`along sanitize`), and quiet test runner (`along test -q`).
   - Transactional rollback via `FileTransaction` if any verification step fails.
   - Advisory branch overlap scanner (`along conflict-check <branch>`).

## Definition of Done for v4.5.0

- [ ] All three target issues implemented, tested with hermetic test suites, and marked done.
- [ ] Merge drivers registered and verified with zero-conflict `git pull` across concurrent branches with modified projections.
- [ ] Documentation conflicts cleanly auto-resolved without creating broken relative links.
- [ ] Code conflict resolution pipeline reliably aborts and rolls back changes whenever tests fail.
- [ ] Documentation updated across `docs/topic--architecture.md`, `docs/topic--cli-reference.md`, and `docs/topic--skills-reference.md`.

# Milestone: v5.0.0 External Agent Harness Interoperability (Pi & DeepSeek Harness)

## Intent

Milestone `v5.0.0` expands Along runtime interoperability beyond initial host environments (Claude Code, Codex, Antigravity, OpenCode, Cursor) into next-generation external agent harnesses:
1. **Pi Coding Agent (`pi`)**: First-class support for the minimalist terminal agent harness (`@earendil-works/pi-coding-agent`), including folder-based skill installation (`~/.pi/skills/`), native `AGENTS.md` context discovery, and in-process/CLI gate enforcement.
2. **DeepSeek Harness (DSH)**: Interoperability with DeepSeek open-source agent harness (`dsh`), verifying its Claude Code and Codex hooks bridges against Along mechanical gate dispatcher (`along_hook.py`) and providing automated configuration.

## Target Scope

- `[feat--pi-harness-support]`
- `[feat--deepseek-harness-bridge]`

## Definition of Done for v5.0.0

- [ ] Pi added to `alongkit.install.PROVIDERS` and `FOLDER_PROVIDERS` with full installer parity.
- [ ] `install-manifest.json` tracks Pi skills with transactional rollback.
- [ ] DeepSeek Harness hook bridge compatibility verified with `along_hook.py`.
- [ ] Automated configuration (`cordis.yml` patch or `along hook install`) documented and tested.
- [ ] Comprehensive documentation and MkDocs integration for Pi and DSH.
- [ ] Zero test regressions across unit and hermetic suites.

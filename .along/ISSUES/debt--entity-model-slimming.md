# Entity model slimming: drop unused entity types and duplicate records

## Usage measured 2026-10-17

Repositories: along, public/dotnet, mempart (root plus 6 package subprojects).

| Entity | along | dotnet | mempart (root + packages) | Verdict |
| --- | --- | --- | --- | --- |
| Issues (open + done) | 44 + 276 | 55 + 88 | 38 + 196, packages 56 + 87 | core, keep |
| Decisions (ADR) | 50 | 0 | 19, packages 2 | keep |
| Sessions logs | 225 | 107 | 132 (~700 KB), packages 67 | keep, slim |
| Milestones | 26 | 3 | 3, packages 1 each | keep, optional |
| Spikes | 0 | 0 | 3 | fold into issues |
| Risks | 1 | 0 | 0 | remove |
| Checklists | 2 | 2 (scaffold) | 3 (2 scaffold + 1 custom), packages 2 scaffold each | remove scaffold |

## Changes

1. **Remove the Risk type.** One record in all repositories. A risk becomes an issue with tag `risk` (or a `debt` issue).
2. **Spikes become an issue type** `spike--<slug>` under `.along/ISSUES/`, with an `## Outcome`
   section and status `done` when concluded. One lifecycle, one board, no separate folder.
3. **Remove scaffolded checklists** (`pre-commit.md`, `stage-completion.md`). They duplicate the
   AGENTS.md checklist and go stale. Procedures are printed by the CLI when they apply (`along wrap`).
   Custom checklists (for example `adaptive-ui-devices`) move to `docs/`.
4. **Slim session logs.** Today a log repeats git (attributed files table) and the plan. Keep front
   matter, summary, decisions and links to run records; drop the attributed files table and the plan
   copy. In autonomous mode the log is generated from run records at wrap.
5. **Clean up blackboards after wrap.** Leftover `.along/.session/<slug>/` folders remain after
   completion (mempart: 1 at root, 3 in packages). `along wrap` archives or removes them; `along session gc` covers old ones.
6. **Stop scaffolding empty files** in subprojects: `VISION.md` and `GLOSSARY.md` of 108-113 bytes in
   five mempart packages, empty `RISKS/` and `SPIKES/`. Create on first use.
7. **One record of completion, not three.** `ISSUES/done/`, `SESSIONS/` and `HISTORY.md` record the
   same event. Keep `HISTORY.md` as a one-line append only, generated by wrap.
8. **Dashboard exports** (`DASHBOARD.md`, `dashboard.html`) belong to the dashboard extra (`debt--along-core-extras-split`).
9. **Migration backups**: dotnet and mempart still hold five `.along/.migration-backup/` snapshots
   each; confirm the retention fix applies on `along update` there.

Migration goes through `migrate_protocol.py` (risks to issues, spikes to issues, checklist removal).

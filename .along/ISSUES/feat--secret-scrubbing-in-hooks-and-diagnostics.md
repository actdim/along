# Secret Scrubbing in Lifecycle Hooks Audit Logging and Diagnostics Isolation

## 1. Context and Problem Statement

Along maintains a sensitive data redaction engine in `alongkit.telemetry.redactor.Redactor`, which contains robust pre-compiled regular expressions for scrubbing private keys, API tokens (`sk-`, `ghp_`, `AKIA`), Bearer tokens, passwords, and home paths. However, this engine is currently wired exclusively into OpenTelemetry / AEP tracing spans.

In contrast, the runtime lifecycle hooks engine (`alongkit.hooks.config.record_audit_entry`) writes gate violation details, tool names, and failure reasons directly into `.along/diagnostics/hooks_audit.jsonl` without redaction. If an agent executes a shell command containing credentials or connection strings (e.g. `curl -H "Authorization: Bearer sk-..."`) and the command is intercepted or denied by `CliSafetyGate`, the raw command snippet or error reason can be written to disk in plain text.

Furthermore, `.along/diagnostics/` is currently not listed in the repository `.gitignore`, posing a risk of accidental secret leaks into version control.

## 2. Objectives and Scope

1. **Connect Redactor to Hook Audit Logging**:
   - Update `record_audit_entry` in `scripts/alongkit/hooks/config.py` to scrub `reason`, `tool`, and error payload fields through `alongkit.telemetry.redactor.Redactor` before serialization.
2. **Sanitize Circuit Breaker Diagnostics**:
   - Ensure `alongkit.circuit` redacts environment variables, command arguments, and stack traces before writing to `.along/diagnostics/circuit_breaker.json`.
3. **Isolate Diagnostics in Git**:
   - Add `.along/diagnostics/` to `.gitignore` and template `.gitignore` files generated by `along-init`.
4. **Verification and Automated Tests**:
   - Add hermetic test cases in `tests/test_hooks.py` asserting that secret strings (`sk-ant-...`, `ghp_...`, passwords) are replaced with `[REDACTED]` in `hooks_audit.jsonl`.

## 3. Requirements

- REQ-1: Import `alongkit.telemetry.redactor.Redactor` in `scripts/alongkit/hooks/config.py` and sanitize all audit entry strings before appending to `hooks_audit.jsonl`.
- REQ-2: Sanitize error reasons and tool invocation arguments logged during circuit breaker trips in `scripts/alongkit/circuit.py`.
- REQ-3: Add `.along/diagnostics/` to root `.gitignore` and `skills/along-init/` scaffolding templates.
- REQ-4: Provide zero-allocation fast path when no sensitive token patterns are present.
- REQ-5: Maintain strict backward compatibility for audit entry JSON schema (`timestamp`, `gate`, `decision`, `mode`, `runtime`, `tool`, `reason`, `conversation_id`, `step_idx`).
